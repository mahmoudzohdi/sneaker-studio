## Run it on your laptop

`fetch()` doesn't work when you double-click `index.html`, so start a small local server in this folder:

```sh
python -m http.server 8000
```

Then open http://localhost:8000.

### Using this template (delete this section when you start)

1. Click **Use this template** → **Create a new repository**. Make it **Public** (GitHub Pages is free for public repos).
2. In the new repo: **Settings → Pages → Branch: `main`, folder `/ (root)` → Save**. Your link appears there within a few minutes.
3. Edit `index.html` section by section. Commit every time something works, then open your live link to check.
4. Before you submit: open the live link on a phone, in a private window. If it doesn't open there, judges can't open it either.
